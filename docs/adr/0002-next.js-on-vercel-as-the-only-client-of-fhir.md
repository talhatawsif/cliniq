# ADR 0002: Next.js on Vercel as the only client of FHIR

Status: accepted (14 November 2026)

## Context

Keep credentials and clinical data access server-side.

## Decision

All FHIR reads and writes happen in server components, route handlers and server actions, using a Google ID token signed from a service-account key. The browser receives rendered pages and JSON the server chose.

## Consequences

The service-account key is a long-lived secret; Workload Identity Federation is the production replacement (see SECURITY.md).
